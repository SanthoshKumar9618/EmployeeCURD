# Employee CRUD System (Java Project)

This is a simple Java console-based application that performs basic CRUD operations (Create, Read, Update, Delete) for managing employee records.  
The project uses core Java concepts such as OOP, ArrayList, packages, and classes.

---

## 📌 Features

- Add new employee  
- View all employees  
- Update employee details  
- Delete employee  
- Console-based interactive menu
